# SkillSwap Platform

A web-based platform designed for skill sharing and exchange between users.

## Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage

## Features
- Skill sharing and exchange
- User-friendly web interface
- Client-side data storage using Local Storage
- Skill and swap request management

## Project Overview
SkillSwap Platform is a web application developed as part of an MCA minor project. 
It provides a platform for users to share their skills and exchange skills with others.

## Project Type
MCA 1st Semester Minor Project
